# TagSDanbooru · Danbooru 标签助手

TagSDanbooru 是一个 Danbooru 标签助手：本地运行的网页，用来搜索、挑选、组合标签，并生成可直接使用的提示词和通配符文件。标签数据随仓库附带，不需要联网。

其中**人气前 5,000 条标签的中文译名与「一级 / 二级分类」已逐条人工补齐**，可以直接按「服装 / 手势 / 眼睛 / 表情」这类分类挑词。

页面里还有一个出图工作台，接你本机的 ComfyUI，方便随手看一眼当前词条的初步效果。它不是 ComfyUI / WebUI 的替代品。

## 📦 前置要求

使用前需要准备：

- **ComfyUI**（可选）：项目不打包 ComfyUI 和模型，出图工作台只是通过 HTTP 调用你本机跑着的那个。不用出图功能可以完全忽略。
- **标签库 CSV**：已随仓库附带（15 万行，约 6 MB，danbooru 2025-05-01 快照），开箱即用；其中**人气前 5,000 条的中文译名与分类已人工补齐**。想换成自己的词库，覆盖 `_internal/data/tagsd_danbooru_zh.csv` 就行。
- **Python 3.8+（含 aiohttp）**：`启动.bat` 会自动查找可用的 python，顺序是 `TAGSD_PY` → `config.json` 的 `comfy.python` → 常见 ComfyUI 路径 → PATH。用 ComfyUI 自带的那个最省事。
- **Chrome / Edge / Brave**（可选）：想要「独立窗口 + 单实例接管」这个体验才需要，留空会自动查找。

> 只想要标签助手、不用出图工作台的话，有标签库 CSV 和一个浏览器就够了，双击 `启动.bat` 即可。

## 🚀 怎么用

1. 双击根目录的 **`启动.bat`**。
2. 会弹出一个独立的页面窗口，默认 `http://127.0.0.1:9000/TagSDanbooru.html`。
3. 页面立刻载入标签库（约 0.4 秒），同时自动拉起 ComfyUI（首次约 20 秒）。
4. 选标签、调参数、出图，都在网页里完成。

想收工时点工作台里的「⏻ 关闭服务」（两步确认），ComfyUI、页面窗口、终端窗口会一起收掉，也可以直接关掉那个命令行窗口。

> **页面窗口和终端窗口都是单实例的。** 反复双击 `启动.bat` 也只会保留一个，新的一次会让上一次干净退出再启动。
> 页面用的是项目专属的浏览器配置目录 `_internal/.browser/`，和你日常浏览器完全隔离，不会往里塞标签页。
> 相关开关都在 `_internal/config.json` 的 `server` 段：`single_window`、`close_window_on_exit`、`browser_exe`。
> 只有从 `启动.bat` 启动时才会接管终端窗口；如果你在自己的命令行里手动跑 `server.py`，程序不会记录任何窗口，也就不会去动你的终端。

> **目录说明**：根目录只需要关注三项，`启动.bat`、`TagSDanbooru.html`、`README.md`。
> 其余都在 `_internal/` 里（标签数据、ComfyUI 工作流、图片资源、出图归档、日志），日常不用进去。

## 🌟 核心功能

- **人工校对的高频标签库**：人气前 5,000 条标签逐条补齐中文译名与两级分类，页面里可按「一级 → 二级」联动筛选。
- **标签管理**：按项目或风格分组，自定义分类，自由增删整理。
- **搜索与发现**：15 万条全库，模糊搜索、自动补全、分类筛选；也可以直接用分类按钮（一级 → 二级联动）挑词；还能自建新标签存进库。
- **提示词构建**：点选组合、自由排序、批量添加、一键清空，实时预览。
- **标签翻译**：中英对照，不用离开页面。
- **提示词生成**：按选好的标签生成标准 Prompt，多种格式，可直接复制。
- **通配符生成器**：把标签集合导出成 wildcard 文件，SimpAI、Fooocus、A1111/Forge、ComfyUI 都能用。

标签数据基于 danbooru 2025-05-01 快照构建；中文译名与两级分类由本项目持续整理，热门词条已逐条人工补齐。

## 🎨 出图工作台

选完标签直接出图，方便随手看一眼这组词条的初步效果，不用离开浏览器，也不用自己开 ComfyUI。

- **提示词**：正向 / 负向输入框，三个一键按钮 `用已选标签` / `用格式化文本` / `还原`；下面还有一个可折叠的「工作流预设词」，用来编辑固定的正向 base 与负面（会写回 `illSdxl.json`）。
- **参数**：模型、采样器、调度器、步数、CFG、宽、高、张数、种子（带随机骰子）、系列。默认值自动从你的 ComfyUI 工作流读取，打开页面就是你原来的配方；采样器/调度器下拉框里带 ★ 的是推荐组合，只是提示，不会改动你选的值。
- **操作**：开始出图 / 中断 / 清空队列 / 释放显存 / 关闭服务。
- **进度**：进度条加 `生成中… 2/5` 实时刷新。

> **工作台只是个看效果的入口。** 选好标签随手配一下、快速出张图，确认这组词大概长什么样，不是拿来正经出图的。
> 它只覆盖提示词和最基本的采样参数，参数面板源自 `_internal/workflows/illSdxl.json` 这一张固定工作流。
> LoRA、ControlNet、hires fix、局部重绘、图生图、放大这些都没有，也不打算做。想在出图上做更多，那还是 ComfyUI 的主场。

> ComfyUI 启动需要十几秒。这期间下拉框显示「（ComfyUI 启动中…）」，状态栏会告诉你已经读到的工作流默认值；
> 就绪后下拉框自动填充，不用刷新页面。

> ⚠️ **画风不由提示词决定。** `_internal/workflows/illSdxl.json` 里标题为「正向base」的**节点 9** 是一段固定前缀，
> 经节点 8 `StringConcatenate` 拼在每条正向最前面；服务端只替换节点 10，也就是你在页面上输入的配方。
>
> 要改画风、质感、光照、细节就改节点 9：**页面工作台里的「工作流预设词 → 正向 base」可以直接编辑并保存**（会写回 `illSdxl.json`），
> 也可以手编 JSON 里的 `inputs.value`。服务端每次出图都重新读盘，改完立即生效，不用重启。
>
> 仓库自带的节点 9 是 `anime illustration, official art, anime coloring …` 这套现代动漫插画风格。
> 页面上的配方只管「谁 + 穿什么 + 表情 + 姿势」，这样 20 来个标签的预算可以全留给内容。

### 出图结果：按「系列」归档

工作台参数里有一个**系列**输入框，同一个系列的图会收进同一个文件夹：

```
_internal/output/
└── OL制服/                        ← 系列
    ├── 20261012_211052_2f37/      ← 一次出图
    │   ├── 01_seed777006.png
    │   └── prompt.json
    └── 20261012_213655_faa0/
        ├── 01_seed424242.png
        └── prompt.json
```

- 系列名留空就按当天日期建文件夹（如 `20261012`），什么都不填也不会乱。
- 浏览器会记住你上次用的系列名，下次打开自动填好。
- 图片按 `序号_seed.png` 命名，每个批次还带一份 `prompt.json`，记录这一批的正负向词和全部参数。

这样同一个主题的迭代过程都躺在一个文件夹里，按时间排下来。

### 结果画廊

画廊读取全部历史出图，不需要去翻文件夹。顶部有两条切换条：

- **系列条**：一行系列，点了就只看那个系列。
- **批次条**：第一个「全部」把这个系列所有批次的图按时间正序拼在一起，翻一遍就是一路改过来的全过程；后面的时间标签则只看那一次。

> 打开页面时会**自动加载**已有出图，不用先点「刷新图片」。
> 之后每次切回窗口会自动同步一次，命令行练图 / 删图后不用再手动点。

| 图标 / 操作 | 说明 |
|---|---|
| 点缩略图 | 页面内灯箱放大，`←` `→` 切换，`Esc` 关闭 |
| 🖿 | 在资源管理器中直接选中这张图 |
| ↻ | 用这张的参数（seed / 步数 / CFG / 尺寸 / 采样器）回填表单，保留构图只改提示词 |
| ⤓ | 把这一批的提示词载入输入框，在其基础上修改 |
| 🗑 | 把这张图送进回收站（两步确认，随时可还原） |
| ↗ | 新窗口打开原图 |
| 「打开文件夹」 | 在资源管理器中打开当前这一批（「全部」时是当前系列）的归档目录 |
| 「删除这一批」 | 把当前这一整批送进回收站 |

> 画廊在**打开页面**、点「刷新图片」或切回窗口时重建。用命令行工具、回收站或资源管理器在外部动过 `output/` 之后，
> 页面不会自己知道，点一下「刷新图片」或切回窗口就对上了。

### 附带的命令行小工具（`_internal/dev/`）

出图不一定非要点网页。这几个脚本给批量练图、排查问题用，调用的是同一个本地接口：

| 工具 | 作用 |
|---|---|
| `gen.py` | 命令行走工作台接口，UTF-8 安全（PowerShell 5.1 直接发中文 JSON 会把系列名编坏，实测 `OL制服` 会变成 `OL__`），支持 `--wait` 等出图完成 |
| `check_prompt.py` | 写提示词前先跑，零 GPU 成本，查标签是否存在、热度分级、别名重复、数量/加权是否超预算 |
| `contact_sheet.py` | 出图后一键拼 3 张检视图：`sheet_*` 总览网格、`face_*` 头部放大、`lower_*` 下半身放大，每格标注 seed / 步数 / CFG / 尺寸。需要 PIL，请用 ComfyUI 自带的 python 跑 |
| `preview.py` | 单张缩图 |
| `selftest.py` | 5 项端到端自检 |
| `check_js.py` / `check_js_syntax.py` | 前端 JS 的结构检查、词法级括号配平检查 |
| `reconcile_output.py` | 出图归档对账，磁盘和画廊对不上时跑一下，会自动跳过 ComfyUI 正在运行的实例 |

```powershell
# 先体检提示词（零 GPU 成本），再出 2 张并等它完成
python _internal\dev\check_prompt.py _internal\dev\prompts\正向.txt _internal\dev\prompts\负向.txt --budget 22
python _internal\dev\gen.py --series 试验 --positive-file _internal\dev\prompts\正向.txt ^
       --negative-file _internal\dev\prompts\负向.txt --count 2 --size 768x1344 --wait
```

> 中文提示词请写成 UTF-8 文本文件用 `-file` 传入（`--series-file`、`--positive-file`、`--negative-file`），
> 不要直接写在命令行参数里，这是 Windows 命令行编码的老问题。

## 📸 数据快照与更新

随仓库附带的 `_internal/data/tagsd_danbooru_zh.csv` 是 danbooru 2025-05-01 时点的标签快照，开箱即用。

数据里的**中文译名与「一级 / 二级分类」由本项目持续维护**：热度最高的 5,000 条标签已逐条补齐译名与分类，其余长尾暂保持原样。补全工具在 `_internal/dev/fill_tags.py`（读「行号;;中文;;一级;;二级」映射，只填空格子，可重复运行）。

页面里的「更新CSV」按钮会从本仓库的 GitHub raw 地址重新下载最新快照、覆盖本地缓存，也就是把这个仓库发布的最新版数据同步到本地。它不是去取 danbooru 官方实时数据，所以只在本仓库更新过 CSV 之后才有意义。

数据文件路径可以用 `_internal/config.json` 的 `paths.tag_csv` 调整。
