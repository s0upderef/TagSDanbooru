# TagSDanbooru · Danbooru 标签助手

**TagSDanbooru** 是一站式 Danbooru 标签助手，旨在彻底简化 AI 绘画的提示词构建流程，尤其针对 Stable Diffusion 等模型的动漫风格图像生成。

它就像一个专门为 Danbooru 标签设计的购物车——轻松浏览、挑选、组合和管理标签，为你下一张杰作构建出最完美的提示词。

> [!TIP]
> 还在手动管理记事本里的标签吗？TagSDanbooru 将帮助你搜索、管理、组合、编辑、翻译标签，并一键生成可用的提示词（Prompt）和通配符（Wildcard），将你从繁琐的工作中解放出来。

> 所有文件可以自行下载，打造自己的标签库。可以本地运行，无需网络，它只是一个静态 HTML 文件，加上 csv 数据文件。

> **一句话定位**：这首先是个**标签 / 提示词创作工具**。页面里的**出图工作台**只是个便利 —— **方便随手看一眼所选词条的初步效果**（一个连到你本机 ComfyUI 的薄启动器），**不是** ComfyUI / WebUI 的替代品（边界见下文「🎨 出图工作台」）。

## 📦 前置要求（先读这一段）

这个仓库是**标签助手 + 出图工作台**（前端页面 + 一个本地服务），**不包含**下面这几样，需要你自己准备：

| 需要什么 | 为什么 | 放哪 / 怎么配 |
|---|---|---|
| **一个能出图的 ComfyUI**（可选） | 项目**不打包 ComfyUI，也不含任何模型**。出图工作台只是通过 HTTP 调用你本机跑着的 ComfyUI | 复制 `_internal/config.example.json` 为 `_internal/config.json`，把 `comfy.python` / `comfy.dir` 改成你自己的路径；不用出图功能就完全不用管它 |
| **标签库 CSV** | 数据**已随仓库附带**（15 万行、约 6 MB，danbooru 2025-05-01 快照），开箱即用 | 就在 `_internal/data/danbooru_all_2.csv`（UTF-8）；想换成自己的词库就覆盖它，或启动后在页面里点「**选择本地文件**」手动加载 |
| **Python 3.8+（需 aiohttp）** | `启动.bat` 跑的是本地服务 `_internal/server.py`，它依赖 `aiohttp`；`启动.bat` 会自动按「`TAGSD_PY` → `config.json:comfy.python` → 常见 ComfyUI 路径 → PATH」的顺序找一个带 aiohttp 的 python | 用 ComfyUI 自带的那个 python 最省事；系统 python 需 `pip install aiohttp` |
| **Chrome / Edge / Brave**（可选） | 想要「独立窗口 + 单实例接管」这个体验 | 留空自动查找，也可在 `config.json` 的 `server.browser_exe` 里指定 |

> 只想要**标签助手**（不要出图工作台）？那就只需要「标签库 CSV + 一个浏览器」，双击 `启动.bat` 即可。

## 🚀 怎么用

1. 双击根目录的 **`启动.bat`**
2. 会**自动弹出一个独立的页面窗口**（默认 `http://127.0.0.1:9000/TagSDanbooru.html`）
3. 页面**立刻**载入标签库（约 0.4 秒），同时自动拉起 ComfyUI（首次约 20 秒）
4. 选标签、调参数、出图，全部在网页里完成

想收工时点工作台里的 **「⏻ 关闭服务」**（两步确认）—— ComfyUI、页面窗口、终端窗口会一起收掉。
也可以直接关掉那个命令行窗口。

> **页面窗口和终端窗口都是"单实例"的**：反复双击 `启动.bat` 永远只有**一个页面窗口 + 一个命令行窗口**
> —— 新的一次会自动让上一次干净退出（停掉它的 ComfyUI、关掉它的页面窗口和终端窗口）再启动。
> 页面窗口使用项目专属的浏览器配置目录 `_internal/.browser/`，与你日常浏览器的配置完全隔离，
> **绝不会往你日常浏览器里塞标签页**。相关开关都在 `_internal/config.json` 的 `server` 段：
>
> | 键 | 默认 | 说明 |
> |---|---|---|
> | `single_window` | `true` | 独立窗口 + 自动接管旧窗口。改成 `false` 则退回"在默认浏览器里开新标签页" |
> | `close_window_on_exit` | `true` | 服务退出时，是否把这个页面窗口一并关掉 |
> | `browser_exe` | `""` | 指定用哪个浏览器；留空则自动查找 Chrome / Edge / Brave |
>
> 只有**从 `启动.bat` 启动**时才会接管终端窗口。如果你在自己的命令行里手动跑 `server.py`，
> 程序不记录任何窗口，因此绝不会去动你的终端。

> **目录说明**：根目录只需关注 3 项 —— `启动.bat`、`TagSDanbooru.html`、`README.md`。
> 其余全部收在 `_internal/`（标签数据、ComfyUI 工作流、图片资源、出图归档、日志），日常不需要进去。
> （`_internal/.browser/` 是上面那个独立窗口的浏览器配置，删掉也无害，下次启动会重建。）

## 🌟 核心功能

* **🏷️ 高效的标签管理**
    轻松管理你的标签库。你可以按项目或风格分组，使用自定义分类，自由地添加、删除和整理标签集合。

* **🔍 强大的搜索与发现**
    支持完整的 Danbooru 标签库（随仓库附带，见上文「前置要求」），支持模糊搜索、自动补全和筛选。帮助你快速找到想要的标签，并发现激发灵感的新标签。还可以创建新标签，并保存到数据库中，以供下次使用。（以 danbooru 2025-05-01 数据源为基础构建，合并了多个来源与人工校正的中文翻译）

* **✨ 便捷的提示词构建**
    通过直观的点选，自由组合和排序标签。你还可以批量添加标签，或者一键清空标签，并实时预览效果。

* **🌐 内置标签翻译**
    无需离开应用，即可在中文、英文等多种语言之间快速翻译标签，帮你理解其确切含义，解锁更多创意。

* **🤖 智能生成提示词**
    根据你挑选的标签，自动生成适配 AI 绘画模型的标准提示词（Prompt），多种格式化，可直接复制使用。

* **`*` 通配符生成器**
    一键将你的标签集合转化为通配符（Wildcard）文件。这对于在 SimpAI、Fooocus、Stable Diffusion WebUI (如 A1111/Forge) 和 ComfyUI 中实现画面元素的随机组合、增加多样性非常有用。

## 🎨 出图工作台

页面里就是出图工作台：选完标签直接出图，**方便随手看一眼这组词条的初步效果** —— 不用离开浏览器，也不用自己开 ComfyUI。

* **提示词**：正向 / 负向输入框，三个一键按钮：`用已选标签` / `用格式化文本` / `还原工作流默认词`
* **参数**：模型、采样器、调度器、步数、CFG、宽、高、张数、种子（带随机骰子）、**系列**
  默认值**自动从你的 ComfyUI 工作流读取**，所以打开页面即是你的原配方
  采样器/调度器下拉框里带 ★ 的是推荐组合（只是提示，不会改动你选的值）
* **操作**：开始出图 / 中断 / 清空队列 / 释放显存 / 关闭服务
* **进度**：进度条 + `生成中… 2/5` 实时刷新

> 🧭 **它不做什么（边界说明）**
> 工作台**只是为了方便看词条的初步效果** —— 选好标签随手配一下、快速出张图，确认「这组词大概长这样」，不是拿来正经出图的。
> 它只覆盖「提示词 + 最基本的采样参数」，参数面板源自 `_internal/workflows/illSdxl.json` 这**一张固定工作流**；
> **LoRA、ControlNet、hires fix、局部重绘（inpaint）、图生图（img2img）、放大（upscale）** 这些进阶能力一概没有，也不打算做 —— 那是 ComfyUI 的主场，请回 ComfyUI 做。
> 换句话说，它是「提示词创作」的延伸，不是「出图工具」的竞品。

> ComfyUI 启动需要十几秒。这期间下拉框显示「（ComfyUI 启动中…）」，状态栏同时告诉你
> 已经读到的工作流默认值；ComfyUI 就绪后下拉框会**自动填充**，不用刷新页面。

> ⚠️ **画风不由提示词决定。** `_internal/workflows/illSdxl.json` 里标题为「正向base」的**节点 9** 是一段固定前缀，
> 经节点 8 `StringConcatenate` 拼在每条正向最前面（服务端只替换节点 10 = 你在页面上输入的配方）。
> 所以「画风 / 质感 / 光照 / 细节」要去那里改：它是 `PrimitiveStringMultiline` 节点的 `inputs.value`，
> 直接编辑 JSON 就行 —— 服务端**每次出图都重新读盘**，改完直接出图即生效，不用重启服务。
> 仓库自带的节点 9 是 `anime illustration, official art, anime coloring …` 这套现代动漫插画风格，想换画风就改这一段。
> 页面上的配方只管「谁 + 穿什么 + 表情 + 姿势」，这样 20 来个标签的预算可以全留给内容。

### 出图结果：按「系列」归档

工作台参数里有一个 **系列** 输入框。同一个系列（同一个主题的反复迭代）的图会收进**同一个文件夹**：

```
_internal/output/
└── OL制服/                        ← 系列
    ├── 20261012_211052_2f37/      ← 一次出图
    │   ├── 01_seed777006.png
    │   └── prompt.json
    └── 20261012_213655_faa0/
        ├── 01_seed424242.png
        └── prompt.json
```

* 系列名**留空则按当天日期**建文件夹（如 `20261012`），所以什么都不填也不会乱
* 浏览器会记住你上次用的系列名，下次打开自动填好
* 图片按 `序号_seed.png` 命名（如 `01_seed777006.png`），一眼看出哪张是哪个种子
* 每个批次的 `prompt.json` 记录了这一批的正负向词和全部参数

这样同一个主题的迭代过程就都躺在一个文件夹里，按时间排下来 —— **一眼能看出改了哪里、哪里变好了**。

### 结果画廊

画廊读取**全部历史出图**，不需要去翻文件夹。顶部有两条切换条：

> 打开页面时**不自动扫**（免得命令行练的图自己冒到页面上）：先点右上角「刷新图片」。
> 之后**每次切回窗口会自动同步一次** —— 命令行练图 / 删图后不必再手动点。

* **系列条** —— 一行系列，点了就只看那个系列
* **批次条** —— 第一个「全部」= 把这个系列所有批次的图**按时间正序拼在一起**，
  翻一遍就是一路改过来的全过程；后面的时间标签则只看那一次

| 图标 / 操作 | 说明 |
|---|---|
| 点缩略图 | 页面内灯箱放大，`←` `→` 切换，`Esc` 关闭 |
| 🖿 | 在资源管理器中直接**选中**这张图 |
| ↻ | 用这张的参数（seed / 步数 / CFG / 尺寸 / 采样器）回填表单 —— **保留构图，只改提示词** |
| ⤓ | 把这一批的提示词载入输入框，在其基础上修改 |
| 🗑 | 把这张图送进回收站（两步确认） |
| ↗ | 新窗口打开原图 |
| 「打开文件夹」 | 在资源管理器中打开当前这一批（「全部」时则是当前系列）的归档目录 |
| 「删除这一批」 | 把当前这一整批送进回收站 |

### 附带的命令行小工具（`_internal/dev/`）

出图不一定非要点网页 —— 这几个脚本是给「批量练图 / 排查问题」用的，调用的是同一个本地接口：

| 工具 | 作用 |
|---|---|
| `gen.py` | 命令行走工作台接口，**UTF-8 安全**（PowerShell 5.1 直接发中文 JSON 会把系列名编坏，实测 `OL制服` 会变成 `OL__`），支持 `--wait` 等出图完成 |
| `check_prompt.py` | **写提示词前先跑**，零 GPU 成本：查标签是否存在、热度分级、别名重复、数量 / 加权是否超预算 |
| `contact_sheet.py` | 出图后一键拼 3 张检视图：`sheet_*` 总览网格、`face_*` 头部放大、`lower_*` 下半身放大，每格标注 seed / 步数 / CFG / 尺寸。⚠️ **需要 PIL**，请用 ComfyUI 自带的 python 跑 |
| `preview.py` | 单张缩图 |
| `selftest.py` | 5 项端到端自检 |
| `check_js.py` / `check_js_syntax.py` | 前端 JS 的结构检查 / 词法级括号配平检查（字符串 / 模板串 / 正则 / 注释都能正确跳过） |
| `reconcile_output.py` | 出图归档对账（见下面「删除图片」一节） |

```powershell
# 先体检提示词（零 GPU 成本），再出 2 张并等它完成
python _internal\dev\check_prompt.py _internal\dev\prompts\正向.txt _internal\dev\prompts\负向.txt --budget 22
python _internal\dev\gen.py --series 试验 --positive-file _internal\dev\prompts\正向.txt ^
       --negative-file _internal\dev\prompts\负向.txt --count 2 --size 768x1344 --wait
```

> 中文提示词请写成 UTF-8 文本文件用 `-file` 传入（`--series-file`、`--positive-file`、`--negative-file`），
> 不要直接写在命令行参数里 —— 这是 Windows 命令行编码的老问题，脚本注释里有说明。

## 🗑 删除图片

删除只是**送进 Windows 回收站**，随时可以从回收站还原，不会真正丢失。

| 操作 | 说明 |
|---|---|
| 图片左上角 🗑 | 删掉这一张（**两步确认**：点一下变红，3 秒内再点才真删） |
| 「删除这一批」 | 删掉当前这一整批 |

几个安全设计：

* **只允许删 `_internal/output/` 里的内容** —— 工作流文件、标签数据永远不会被碰到
* **送回收站失败就报错、不删** —— 不会出现「以为进了回收站、其实永久删了」
* 生成中的批次不允许删（先中断）
* 删掉一批里最后一张图时，整个批次目录一起进回收站
* 某个系列被删空时，空的系列文件夹也会一起进回收站（不留空壳）

> **对账工具**：如果你手动挪动过图片、或在回收站里还原过文件，画廊可能与磁盘不一致。
> 跑一下这个脚本即可自动修正（会自动跳过 ComfyUI 正在运行的实例，安全）：
>
> ```powershell
> python _internal\dev\reconcile_output.py
> ```

### 命令行删了图，页面为什么还显示？

画廊是**点「刷新图片」时才重建的页面快照**，而 `/local/runs` 读的是**服务进程内存里的批次表**
（磁盘扫描只在服务启动时做一次，见 `server.py` 的 `load_runs_from_disk()`）。
所以用 `gen.py`、回收站、资源管理器在外部动过 `output/` 之后，页面不会自己知道：

| 层 | 会不会自己更新 | 说明 |
|---|---|---|
| 磁盘上的图 | — | 确实没了（已删图的 URL 直接 404） |
| 服务端 `/local/runs` | ✅ 一直是对的 | 会过滤掉磁盘上已不存在的文件、以及目录已消失的批次 |
| 页面画廊 | ❌ 要触发一次 | 点「刷新图片」／切回窗口（自动同步）／自己出完图 |

> 还有一层浏览器缓存：服务端的静态响应以前只有 `ETag`、没有 `Cache-Control`，
> Chromium 会自己「猜」一个保鲜期，于是已删的图可能又从缓存里显示出来。
> 现在统一补了 `Cache-Control: no-cache`（每次都带 ETag 去校验，没变就是 304，本地服务零感知）。

> 删掉的那一格也不会留在页面上：`galleryItems()` 会过滤掉**已结束批次**里「没有图」的格子
> （图片被删 / 生成失败），所以删图后画廊不会多出一个空荡荡的「等待中」格子，
> 批次标签、系列角标和「全部」视图的张数也不会虚报。

## ⚡ 为什么打开这么快

标签库有 15 万行。服务启动时会自动把它转成 `_internal/data/danbooru_all_2.json` 缓存，
页面首屏直接 `JSON.parse` —— 比现场逐字符解析 CSV 快两个数量级。

| | 首屏耗时 |
|---|---|
| 改动前（CSV 逐字符解析 + 5 秒倒计时 + 2 秒等待） | ≈ 17 秒 |
| 改动后（JSON 缓存 + 立刻加载） | **≈ 0.4 秒** |

缓存只在**不存在**或**比 CSV 旧**时才重建（约 0.2 秒）。换了标签数据后重启服务即自动更新。

## 📸 数据快照与更新

随仓库附带的 `_internal/data/danbooru_all_2.csv` 是 **danbooru 2025-05-01** 时点的标签快照

`paths.tag_csv` 调整。
